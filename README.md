# 🌍 Country Capitals Quiz

A simple web app to test your knowledge of country capitals. Built using **Node.js, Express, EJS, and PostgreSQL**.

## 🚀 Features

* Random country question
* User inputs capital
* Score tracking
* Instant correct ❌ / wrong ✔ feedback
* Game over alert + restart option

## 🛠 Tech Stack

* Node.js
* Express.js
* EJS (templating)
* PostgreSQL
* HTML, CSS, JavaScript

## 📂 Project Setup

### 1. Install dependencies

npm install

### 2. Setup database

* Create a PostgreSQL database
* 👉 “Import data/capitals.csv into PostgreSQL table”

### 3. Run server

node index.js

### 4. Open in browser

http://localhost:3000

## 🎮 How it works

1. App shows a country
2. User enters capital
3. If correct → score increases
4. If wrong → game over + restart option
